# Employee training matrix template

A free Excel workbook for tracking who is trained, what expires next, and which evidence is on file.

## What is inside

- `People` - employee ID, name, role, site, and status
- `Requirements` - which training each role and site requires
- `Training records` - completion date, expiration date, evidence reference, and approval status

Download the workbook: [employee training matrix template](https://trainingtrackerhq.com/training-matrix-template)

## How to use it

1. Fill the People sheet first. Use an employee ID, not just a name.
2. Define requirements by role and site.
3. Import existing completion rows and keep the historical dates.
4. Review expired and due-soon items before each audit.
